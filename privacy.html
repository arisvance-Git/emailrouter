Privacy policy

EmailRouter · Effective 8 October 2026

EmailRouter is a private automation used by one person on their own Google account. It has no other users, accounts, website features or analytics.

What data it accesses

  • Gmail: message headers (sender, subject, authentication results), attachments of messages that match the owner's routing rules, and message labels. It sends summary emails to the owner.
  • Google Drive: the folders named in the owner's routing rules, to save attachments and avoid duplicates.
  • Google Sheets: read-only access to the owner's routing-rules spreadsheet.

How the data is used

Data is used only to file the owner's attachments into the owner's Drive, move processed or unwanted messages to the owner's Gmail Trash, and send the owner a summary. Nothing is used for advertising, profiling or any other purpose.

Where data goes

Data stays within the owner's Google account and the owner's Google Cloud project, where the automation runs. It is not sold, shared with or transferred to any third party. Operational logs (such as email subjects and senders of processed messages) are kept in the owner's Google Cloud Logging for up to 30 days.

Storage and security

The authorization token is stored encrypted in a private Cloud Storage bucket in the owner's project, readable only by the automation and the owner. Access to it is audit-logged.

Revoking access

The owner can revoke EmailRouter's access at any time at myaccount.google.com/permissions.

Limited Use

EmailRouter's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

Changes to this policy are published on this page. Questions: open an issue at github.com/arisvance-Git/emailrouter.
